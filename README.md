# FPGA - LSD / ISD

Pequeno projeto em HTML, CSS e JavaScript, inspirado nas aulas práticas de LSD e ISD de Engenharia de Computadores e Telemática da Universidade de Aveiro.

A página simula os seis displays de sete segmentos de uma placa Alinx Cyclone IV. Ao carregar em **Ligar FPGA**, os displays fazem uma pequena contagem e mostram um código de seis algarismos. O mesmo botão permite desligar a placa e apagar os displays.

Para experimentar, basta abrir `index.html` num navegador. Não é necessário instalar nada. Também funciona no GitHub Pages.

O código apresentado pode ser alterado na constante `SECRET_CODE`, dentro de `index.html`. Deve conter seis algarismos.
